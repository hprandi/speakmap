# Naming

- Everything in the repository is in English (EN-US).
- Files are PascalCase and named after what they export (`WebSpeechTranscriber.ts`).
- Folders are lowercase, kebab-case when they have several words (`transcriber/web-speech/`).
- Each implementation of a swappable component has its own subfolder (`interpreter/claude/`).
- Shared types and contracts live in `domain`.
